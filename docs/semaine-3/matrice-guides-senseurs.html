Aucun générateur de code dédié ni aucune revue automatisée dans une CI n'a été trouvé dans le dépôt. Les quatre cases de la matrice ne sont donc pas remplies artificiellement.

Boucle de vérification

1 · Guider

Cahier des charges, architecture et instructions Copilot orientent la modification.

2 · Exécuter

Typecheck, lint, tests et build produisent un retour observable.

3 · Corriger

L'échec est analysé, corrigé, puis la commande est relancée ; la validation humaine clôt la boucle.

Source : bilan semaine 8 du projet Gesta.
